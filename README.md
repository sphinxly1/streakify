# ⚡ Streakify — Habit & Streak Engine

Streakify is a lightweight, responsive web application designed to help users build discipline, track daily check-ins, and hit targeted habit challenge durations. Built using modern HTML, Tailwind CSS, and vanilla JavaScript, it stores all data directly in the browser via `localStorage`.

---

## ✨ Features

- 🎯 **Target Goal Durations:** Set habit challenges with preset (7, 14, 30, 60 days) or custom target durations.
- 🔥 **Streak & Momentum System:** Track your current and maximum streaks. Missed check-in banners notify you when streaks reset.
- 📊 **Consistency Heatmap:** Visual 14-day activity grid providing an overview of overall check-in consistency.
- 📝 **Habit Journal & Reflections:** Add initial intentions and edit daily journal notes for each habit entry.
- 🎉 **Reward Animations:** Celebratory confetti animations upon check-in and trophy modals upon 100% challenge completion.
- 🎨 **Minimal & Modern UI:** Clean light mode interface styled using Tailwind CSS and Lucide Icons.
- 💾 **Local Storage Persistence:** All habits, check-in history, and notes persist seamlessly in your web browser.

---

## 🛠️ Tech Stack

- **HTML5:** Semantic structure.
- **Tailwind CSS (via CDN):** Modern utility-first styling.
- **Vanilla JavaScript (ES6+):** Dynamic DOM updates, state management, and modal controls.
- **Lucide Icons:** Crisp vector iconography.
- **Canvas Confetti:** Interactive celebratory effects.

---

## 🚀 Quick Start & Usage

1. **Clone or Download the Repository:**
   ```bash
   git clone https://github.com/sphinxly1/streakify.git
   ```

2. **Run the Application:**
   Open `index.html` directly in any web browser. No complex build step or backend node server is required.

3. **Managing Habits:**
   - Click **"Add Habit"** to define a title, category, frequency, target challenge duration, and notes.
   - Click **"Check In Today"** to log daily progress.
   - View recent check-in status tiles on each habit card or analyze consistency in the **Analytics** section.
